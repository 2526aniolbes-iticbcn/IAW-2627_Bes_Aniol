Aquest repositori recull les pràctiques, els exercicis i les activitats realitzats durant el curs de l'assignatura **Implementació d'Apps Web**.

## 🗂️ Organització

Cada pràctica o exercici disposa de la seva pròpia carpeta, que conté els fitxers corresponents a l'activitat.

L'estructura del repositori segueix aquest model:

    implementacio-apps-web/
    ├── README.md
    ├── practica-01/
    │   └── ...
    ├── practica-02/
    │   └── ...
    └── practica-03/
        └── ...

## 🎯 Objectiu

Centralitzar les activitats de l'assignatura en un únic repositori de GitHub, mantenint una estructura ordenada i facilitant-ne el seguiment i l'avaluació.
